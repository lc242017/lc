## 三、部署步骤

### 3.1 一键部署（推荐）

```bash
# 1. 配置密钥（密钥不落盘）
cp .env.example .env
# 编辑 .env 填入 DEEPSEEK_API_KEY、数据库口令等

# 2. 启动全部服务
docker compose up -d

# 3. 访问
# Superset   http://localhost:8088   admin/admin
# Streamlit  http://localhost:8501
# ECharts    直接双击 echarts/index_standalone.html（离线可开）
```

`docker-compose.yml` 含 `depends_on + healthcheck`：Superset 健康后才启动 App。

### 3.2 数据链路回放（按序串行）

```bash
bash hr.sh sql/clean/00_init.sql
bash hr.sh sql/clean/01_enum_standard.sql
bash hr.sh sql/clean/02_abnormal_format.sql
bash hr.sh sql/clean/03_split_merge.sql
bash hr.sh sql/clean/04_quality_report.sql
bash hr.sh sql/dwd/10_ddl_dim.sql
bash hr.sh sql/dwd/11_ddl_fact.sql
bash hr.sh sql/dwd/12_etl_dim.sql
bash hr.sh sql/dwd/13_etl_fact.sql
bash hr.sh sql/ads/20_eda.sql
```

> 必须串行：02 依赖 01 视图、03 依赖 02 视图、13 依赖 03 表与 12 维度表。
> 可重复执行：DDL 用 `drop table if exists`，加载用 `insert overwrite`。

### 3.3 数据刷新流程

```bash
cd app
python3 export_data.py        # Hive ADS → echarts/data/*.json
python3 sync_to_mysql.py      # JSON → MySQL ydsh_ads（Superset 数据源）
cd ../echarts
python3 build_standalone.py   # 重新生成离线大屏
```

### 3.4 本地无 Hive 环境（SQLite 同构替身）

```bash
pip install -r requirements.txt
python etl/gen_dwd.py          # 生成 DWD 明细（本地模拟）
python etl/run_etl.py          # DWS/ADS + KPI + 口径校验
python forecast/forecast_gmv.py
python nl2sql/cli.py           # 5 个示例问题
```

## 四、常见问题（FAQ）

| 问题 | 原因 | 解决 |
|---|---|---|
| HiveServer2 反复 Exit(1)，报 `running as process 7` | 残留 pid 文件，PID 7 被新进程占用 | 把 `/opt/hive/conf/hiveserver2.pid` 改成不存在的 PID 再启动 |
| Superset 初始化空库失败 | 手册命令顺序错误 | 按 `db upgrade → create-admin → init` |
| 容器内连不上宿主机服务 | `host.docker.internal` 解析为 IPv6 | 用 Docker 网桥 IPv4 网关 `172.17.0.1` |
| MySQL 连接被拒 | 端口映射非默认 | 用 3307 而非 3306 |
| Superset 连 Hive 失败 | 官方镜像无 Hive 驱动 | 用提供的 `superset/Dockerfile` 构建定制镜像，或先同步到 MySQL |
| NL2SQL 无 Key 报错 | 未配置大模型 | 复制 `.env.example`，或走 offline-mock 模式 |
| pip / CDN 下载超时 | 环境网络出口限制 | 用离线版大屏；依赖就绪环境再启动 UI |
