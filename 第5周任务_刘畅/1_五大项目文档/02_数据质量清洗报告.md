## 一、五类脏数据判定规则

| 类别 | 判定规则 | 处理策略 |
|---|---|---|
| 缺失值 | 字段为 NULL 或空串 | 分类处理：金额/数量不填充直接剔除；枚举填"未知"；email 保留不填充 |
| 重复值 | 业务键（order_id）重复 | 保留"时间最晚 + 金额最大"一条，其余去重 |
| 枚举不规范 | 枚举字段取值不在标准字典内 | 建立映射总表统一标准化（如支付方式、订单状态、渠道） |
| 异常值 | 数值超出合理区间（如金额、年龄） | 金额用缩尾（winsorize），年龄用有效区间均值 |
| 格式不规范 | 日期多格式、时间戳、邮箱格式异常 | 统一日期格式；无法识别的日期置 NULL 不猜测 |

## 四、处理策略与理由（答辩重点）

1. **异常金额用缩尾而非删除**：极端值仍是真实交易，删除会低估 GMV；缩尾保留样本同时抑制长尾影响。
2. **年龄用有效区间均值而非全表均值**：全表均值受异常年龄污染，有效区间均值更稳健。
3. **email 缺失不填充**：邮箱非核心字段，随意填充会引入虚假信息，保留缺失更诚实。
4. **去重保留"时间最晚 + 金额最大"**：代表用户最终且最完整的下单意图。
5. **日期认不出置 NULL 不猜**：错误日期比缺失日期危害更大，避免污染时间维度分析。
