# 指标定义文档（指标口径唯一来源）

> 先定口径，再算数。所有 DWS/ADS 计算、看板展示、NL2SQL 问数均以本文为准。
> 版本：v1.2　维护人：数据组　更新时间：2026-11-09

## 0. 通用约定

| 项 | 约定 |
|---|---|
| 事实表 | `dwd.dwd_order`（一单一品粒度） |
| 有效订单 | `status = 'paid'`，即已支付且未退款；`refunded` / `closed` 不计入任何金额类指标 |
| 金额单位 | 人民币元，保留 2 位小数 |
| 时间口径 | 按 `order_date`（下单日期）归属，不做跨时区换算 |
| 用户口径 | `user_id` 全局唯一，去重统计 |
| 门店口径 | `store_id` 全局唯一；线上单归属发货门店 |

## 1. 核心指标

| 指标 | 英文/缩写 | 计算口径 | 单位 | 备注 |
|---|---|---|---|---|
| GMV | GMV | `sum(pay_amount)` where status='paid' | 元 | 实付口径，不含运费与优惠券补贴 |
| 订单量 | orders | `count(distinct order_id)` | 单 | 一单一品，故等于订单明细行数 |
| 客单价 | AOV | `GMV ÷ 订单量` | 元 | 先汇总后相除，不取各行客单价均值 |
| 活跃用户数 | active_users | `count(distinct user_id)` where status='paid' | 人 | 有下单行为即算活跃，不含仅浏览 |
| 复购率 | repurchase_rate | `下单≥2次用户数 ÷ 下单用户数` | % | 窗口口径；跨月对比用自然月口径 |
| 件单价 | UPT | `订单量 ÷ 购买件数合计` | 件/单 | 辅助指标，用于观察凑单行为 |

## 2. 易踩坑的口径争议点

1. **GMV 是否含退款**：统一用「有效订单」口径。退款单在 DWD 已打标，DWS/ADS 不再二次过滤。
2. **客单价能不能直接 `avg(pay_amount)`**：不能。必须 `sum/sum`，否则大额订单被平均稀释。
3. **复购率窗口**：180 天累计复购率天然高于自然月复购率，两者不可混用；对外汇报需注明窗口。
4. **门店归属**：线上订单按履约门店归属，不按用户注册地，避免"线上销售无门店"。
5. **金额精度**：中间计算不 round，出口统一 `round(...,2)`，避免逐行四舍五入累积误差。

## 品类销售占比（v1.1 新增）

- 口径：某品类 GMV ÷ 全部 GMV（有效订单口径）；
- 落表：`ads.ads_category_top10.sales_share`（同时保留销售额 `sales` 与订单量 `cnt`）；
- 用途：品类结构分析、备货结构决策。

## 用户价值分层（v1.1 新增，RFM 简化版）

- 分层方法：按用户累计 GMV（有效订单）`ntile(4)` 降序四分位；
  前 25% = 高价值，其后依次为成长 / 一般 / 低频；并列值切分随机，属可接受近似；
- 明细表：`ads.ads_user_value`（user_id / orders / gmv / last_order_date / value_tier）；
- 汇总表：`ads.ads_user_tier_summary`（各层人数、GMV、GMV 占比）；
- 用途：差异化运营——高价值层做留存，成长层做升档，低频层做召回。
