## 三、技术栈

- **数据仓库**：Hive 4.0.0（Tez 执行引擎）+ Derby Metastore，Docker 三容器部署
- **ETL 与建模**：SQL（分区表、动态分区、去重、`row_number()`）、Python（pandas / statsmodels）
- **分析与预测**：趋势分解、季节性建模，MAPE 16.35%（优于两个基线）
- **智能问数**：NL2SQL（LangChain + LLM，Schema 约束 + Prompt 工程）
- **可视化**：Streamlit、Apache Superset、ECharts 独立大屏
- **性能**：查询优化前后压测，提速 59% / 71%
- **工程规范**：Conventional Commits、`.env` + `.gitignore` 敏感信息隔离
