## 三、执行中遇到的问题与解决（技术坑记录）

| # | 问题 | 解决方案 |
|---|---|---|
| 1 | `percentile()` 在 Hive 4.0 不支持 double 类型 | 改用 `percentile_approx()` |
| 2 | 单次提交 366 个动态分区时 MoveTask 元数据回滚失败（Hive 4.0 + Derby 元数据库的 savepoint 缺陷；3 分区小批量试验正常，定位为批量大小问题） | 生成分批加载脚本，每批 25 个日期，共 15 批 |
| 3 | `dim_product` 品类存在隐藏空格脏值（如"家居生活␣"），导致品类分析每个品类分裂为两行 | 重建维度表时对 category/sub_category/brand 统一 `trim()`，并回写进建模脚本 |
| 4 | 会话执行环境差异 | Git Bash 下 docker exec 路径需 `MSYS_NO_PATHCONV=1`；docker cp 用 PowerShell 免转义 |
