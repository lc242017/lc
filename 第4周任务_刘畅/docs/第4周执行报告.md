## 三、压测结论

| 查询场景 | 平均耗时(s) | 相对全表扫描 |
|---|---:|---:|
| 全表扫描（无分区） | 8.572 | 基线 |
| 分区裁剪（11月） | 3.475 | **提速 59%** |
| 分区+列裁剪（半年GMV） | 6.081 | 提速 29% |
| ADS 预聚合表查询 | 2.502 | **提速 71%** |

分区裁剪显著减少扫描量；ADS 预聚合表把计算前置到离线阶段，在线查询最快。

## 五、限制与说明

1. **Superset 仪表板 UI**：图表/Dashboard 的鼠标操作需在 Superset UI 手工完成，
   本执行已完成数据层准备（ADS 表 + 连接配置），并提供 5 类图表的字段映射说明。
2. **Hive 驱动**：官方 Superset 镜像默认无 Hive Python 驱动，连 Hive 需用提供的
   Dockerfile 构建定制镜像；或先把 ADS 表导入 MySQL 再用 pymysql 连接。
3. **第 3 周代码缺失**：NL2SQL 采用基于 ADS 指标层的降级实现（规则解析 + 预计算数据），
   无需大模型 API 即可运行；完整版可设 `USE_HIVE=1` 切换实时查询。
4. **New Retail 场景**：所有数据均为真实 Hive 表数据，非模拟占位。
